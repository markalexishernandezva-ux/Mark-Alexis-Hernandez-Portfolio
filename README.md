# Mark Alexis Hernandez — Portfolio

Senior Executive Assistant & Digital Operations Specialist.

Static website, no build step.

- `index.html` — the page
- `style.css`, `app.js` — styles and behavior
- `assets/work/` — portfolio images (every project gallery)
- `assets/fa/` — Font Awesome icons (self-hosted)

## Publish with GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
The site then appears at `https://markalexishernandezva-ux.github.io/Mark-Alexis-Hernandez-Portfolio/`.
